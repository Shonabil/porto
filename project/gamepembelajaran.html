Penjelajah Hijau
Game-Based Learning · IPAS · Elementary

Project Overview

Penjelajah Hijau is an interactive web-based digital learning application designed specifically for elementary school students to understand the IPAS topic of plant reproduction. It packages abstract concepts such as perfect and imperfect flowers, generative reproduction (seeds), and vegetative reproduction (natural & artificial) into a fun visual adventure, complete with a bee character as a guide, a virtual world map, and a badge reward system.

The main goal of this project is to bridge text-heavy lessons into an active learning experience through a game-based learning approach. For students, it boosts interest, motivation, and memory retention because learning happens while playing; for teachers, it provides teaching media aligned with the Learning Outcomes (CP) and Learning Objectives (TP), plus an assessment tool through quizzes and games that can monitor student progress.

Key Features

A learning adventure with features that are interactive, playful, and aligned with the curriculum.

Student Login & Profile

Name and school input saved in localStorage, displayed as the student's personal identity on every page.

Interactive Tab Materials

Complete learning content (flower introduction, generative, and vegetative) with tab navigation and responsive plant image cards.

3-Zone Adventure Map

A virtual world of 1920×1080 with a panning camera system, locked/unlocked zones, and saved level progress.

3 Game Levels with Different Mechanics

Level 1 "Root Bridge" (spinning wheel quiz), Level 2 "Totem Statue" (generative vs vegetative drag & drop), Level 3 "Ancient Temple" (assembling flower part labels).

Interactive Quiz — 30 Questions

Multiple choice with a 15-second timer, progress bar, instant feedback, educational facts, and a final score screen.

Guide & Learning Targets

A How-to-Play page plus a CP & TP page that maps every mission to specific learning objectives.

Development Process

The project was developed with an iterative, responsive-first approach, starting from the learning flow design (start → login → main menu → material/game/quiz), then UI development, then coding the interactivity, and finally testing across various screen sizes. Each page was built one by one with full visual consistency — a green-yellow nature palette, Fredoka One & Nunito fonts, and bee, cloud, and star-shimmer animation themes — to maintain the application's brand identity.

The separation of roles across pages (navigation between HTML files) makes development modular and easy to fix; all image assets (characters, maps, plants) and audio (correct/wrong effects) are stored separately in the pictures/ and videos/ folders. Built with HTML5, Tailwind CSS, and vanilla JavaScript, the app uses the localStorage API to save student identity and level progress without a server.
