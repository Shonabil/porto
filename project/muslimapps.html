Muslim Apps
Prayer Time · Al-Qur'an · Dzikir

Project Overview

Muslim Apps is a comprehensive Islamic application designed to help Muslims worldwide in their daily religious practices. The app provides accurate prayer times, Quran readings with translations, daily duas, and inspiring Islamic articles.

Built with modern technologies, this application offers a seamless user experience with beautiful animations and intuitive navigation. The app supports multiple languages and provides notifications for prayer times based on user's location.

Fitur Unggulan

Supporting daily worship with features that are comprehensive, lightweight, and easy to use anytime.

Prayer Times & Imsakiyah

Accurate prayer times for cities worldwide. Simply enter your city name without enabling GPS.

Al-Quran

Read complete Quran with translations, tafsir, and clear audio recitations.

Daily Duas

A collection of daily supplications, safety prayers, and essential duas with transliteration and meanings.

Dhikr

Daily dhikr collections including morning and evening remembrance.

Islamic Articles

Curated articles, inspiring stories, and light fiqh discussions for daily learning.

Qibla Direction

Accurate Qibla compass to help you find direction of Kaaba from anywhere in world.

Development Process

The development focuses on creating a user-friendly interface that respects Islamic aesthetics while maintaining modern design principles. In-depth research was conducted to ensure accuracy of prayer times and religious content.

The application was built using Laravel for a robust backend, ensuring consistent performance. System optimization was carried out to keep the application responsive and stable under various conditions of use.

Technologies Used

Laravel Tailwind CSS MySQL API Integration Github RESTful API
