Flowly
Productivity Dashboard · All-in-One · Laravel

Project Overview

Flowly is a personal productivity dashboard on the web (Laravel 12) that unites four main modules in a single platform: Task & Project Management (a task list with priorities, schedules, and progress-bar projects), Calendar (daily event agenda), Finance (transaction recording plus subscription tracking), and Focus Timer (pomodoro-style focus sessions linked to tasks).

Its goal is to become a one-stop daily "command center", replacing the need to switch between a task manager, calendar, budgeting app, and timer. The main advantage is cross-module data integration: one task can connect to a project plus a focus session; subscriptions that fall due appear alongside monthly expenses; and a summary of everything (today's tasks, late tasks, events, project progress, focus statistics) shows up on the dashboard.

Key Features

A productivity dashboard with features that are integrated, modular, and all in one place.

Unified Dashboard

Today's tasks, late tasks, inbox count, today's events, monthly income/expense, subscriptions due within 7 days, active focus session, project progress, and a real-time global search across all modules.

Task & Project Management

Task statuses (inbox/todo/in_progress/done), color-coded priorities, due dates, schedules, estimated vs actual time, soft-delete, drag & reorder, and quick capture with natural language date parsing in Indonesian ("besok jam 5 sore", "lusa", "minggu depan").

Project Progress

Projects with colors, icons, and archive, whose progress is automatically derived from the ratio of completed tasks.

Finance & Subscriptions

Income/expense transactions with categories, payment methods & notes; subscriptions with billing cycles converted to a monthly equivalent plus days-until-bill, weekly reports per category, and a 7-day summary.

Calendar

Event CRUD with start/end times, all-day support, colors, and relations to tasks, exposed through a JSON endpoint for the frontend.

Focus Timer Linked to Tasks

Start, pause, cancel, or complete a pomodoro-style focus session tied to a task; when completed, actual minutes are automatically added to that task.

Development Process

The project started with framework & authentication scaffolding using Laravel 12 and Laravel Breeze as the foundation. The schema was developed iteratively — 43 migration files show the gradual process, where each module was built and then enriched (for example, the tasks table started basic, then gained user_id, schedule fields, status & priority, soft-delete, project_id, and sort order). Data isolation is enforced by scoping every query with user_id, protected by auth + verified middleware.

For testing, Pest PHP is used (tests/Feature, tests/Unit) — still the built-in ExampleTest, with no module-specific tests yet. Conventions follow Model binding & Form Request in controllers, Blade views, and Laravel Pint style. Setup is automated through a composer setup script (install deps + env + migrate + build) and composer dev (running the server, queue, and Vite together).
